# Random Color Generator

This project is a web application that generates random colors and displays them in a grid of color boxes. Each color box shows the corresponding hexadecimal color code. The application is built using HTML, CSS, and JavaScript, and utilizes Bootstrap for styling. Users can see a variety of colors dynamically generated each time they load the page.

## Features
- Generates 30 random color boxes
- Displays hexadecimal color codes
- Responsive design with Bootstrap
- Hover effects for color boxes

## Technologies Used
- HTML
- CSS (with Bootstrap)
- JavaScript
